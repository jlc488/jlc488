# Sin-Kang (강신)

Founder & CEO of **[DevsLab](https://devslab.kr)** — a SaaS development studio in Seoul.
I ship production SaaS first, then open-source the parts worth sharing.

## Now building

- **[AskLinq](https://getasklinq.app)** — an AI agent that answers visitors from the
  materials you register and hands anything it can't answer to a person. QR-first,
  live in production on [Cloudflare Workers](https://workers.cloudflare.com) +
  PostgreSQL/pgvector. Free beta.
- **[GitLinq](https://devslab.kr/products/gitlinq/)** — a Windows Git client for teams
  coming from SVN: author-first history, and a preview before any change is cancelled.
  Preview.
- **[TraceLinq](https://gettracelinq.app/)** — local visibility, recovery, and replay
  for Claude Code and Codex work. Early access.
- **[VisionLinq](https://getvisionlinq.app/)** — a document AI API that turns images,
  PDFs, and office files into structured fields with source references. Preparing
  for launch.
- **[BookLinq](https://getbooklinq.app/)** — WhatsApp-centered booking for local
  businesses in India. Preparing for launch.
- **Chatur-AI** — voice AI for Indian call centers, built with an operating partner.
  In development.

We also build and run the operations systems of two dental-logistics companies —
EDS Logistics and FM Dental Service.
